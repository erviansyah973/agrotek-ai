🔌 API Endpoint untuk Integrasi

Method Endpoint Fungsi
POST /api/iot/ingest Terima data sensor dari gateway
GET /api/iot/status Cek status IoT server
GET /iot/data/devices Daftar semua device
GET /iot/data/readings Pembacaan sensor terbaru

Contoh payload POST ke /api/iot/ingest: 

{
  "device_code": "AWLR-BDD-01",
  "parameter": "water_level",
  "value": 185.5,
  "unit": "cm",
  "timestamp": "2026-09-15T08:00:00"
}
